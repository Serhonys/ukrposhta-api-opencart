# Укрпошта 2.0 для OpenCart 3 / OcStore 3

Модуль доставки і накладних для **OcStore 3.0.x / OpenCart 3.0.x**. PHP 7.2+, cURL, mbstring.

Мова адмінки модуля: українська або російська. Береться з мови панелі, перемикач УКР / РУС у шапці модуля її замінює. Лист покупцю йде мовою замовлення.

## Що вміє

- Express / Standard, відділення і кур'єр
- Живий тариф після вибору індексу, кеш ціни, резерв або приховування способу
- Checkout: місто, відділення, вулиця з класифікатора
- Накладні: чернетка, створення ТТН, ярлик, трекінг, видалення лише після успіху в API
- Група відправлень, форма 103а, ярлики групи
- Трекінг → статус замовлення, лист клієнту, лист і Telegram продавцю
- Cron: `task=track` і `task=queue`, ключ у налаштуваннях

## Встановлення

1. Залийте архів у **Доповнення → Встановлення доповнень** (у корені zip лежать `upload/` і `install.xml`).
2. **Доповнення → Модифікатори → Оновити**.
3. **Доповнення → Доставка → Укрпошта → Встановити → Редагувати**.
4. Відправник: Bearer eCom, Bearer трекінгу, counterparty token, UUID, індекс.
5. Увімкніть модуль і потрібні способи. Відкрийте налаштування ще раз після оновлення з 1.0 — таблиці добудуються самі.

Видалення модуля **не** стирає накладні. Очищення бази — вкладка «База».

## Cron

Посилання є на вкладці «Трекінг». Порожній ключ вимикає cron.

```
index.php?route=extension/shipping/ukrposhta/cron&task=track&key=...
index.php?route=extension/shipping/ukrposhta/cron&task=queue&key=...
```

Трекінг варто кликати раз на годину. Листи не відправляються в момент зміни статусу, а забираються з черги `task=queue` (раз на 5–15 хвилин).

## Обмеження

- Стандартний checkout OpenCart. Simple / Journal треба підключити ті самі URL або шаблон `ukrposhta_fields`.
- Форма 103а і група залежать від договору: тип групи має збігатися з типом ТТН (EXPRESS або STANDARD).
- Viber і SMS продавцю лише зарезервовані в черзі, робочі канали — email і Telegram.
